CASE STUDY / 01

StudyCompare AI

从分散的学校资料，到一张口径清楚、能追溯来源的比较表。

打开交互 Demo ↗

01 业务问题

学校费用散落在不同网页，学年和学生类别常不一致。家长需要横向比较，也需要知道哪些信息尚未核验。

02 解决方案

浏览学校 → 选择 2–5 所 → 按统一学年比较 → 查看来源与缺失提示 → 导出 CSV 或在当前浏览器保存。

03 技术架构

默认静态模式：浏览器读取公开 JSON 并执行确定性比较。正式产品可配置切换为 FastAPI 接口，继续使用 JSON / SQLite 数据层；两种模式共用页面与比较契约。

04 AI 使用边界

当前核心流程不调用模型。金额由确定性代码计算；缺失值不当作零。未来 AI 可辅助理解筛选意图，不负责编造金额和来源。

05 当前边界

20 所学校、虚构费用样例、无需注册。未接入实时官网数据，未测量节省时间或成本；GitHub 仓库地址待配置。
